## 🚀 Featured Projects

### 1. Customer Segmentation

Segmented 8,950 credit card customers using K-Means, Hierarchical Clustering, and DBSCAN. Applied feature engineering, log transformations, correlation filtering, and PCA to identify actionable customer segments and develop marketing and credit-risk recommendations.

**Tech Stack:** Python · Pandas · Scikit-learn · PCA

[![View Project](https://img.shields.io/badge/View_Project-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/sakibzzz641/Customer-Segmentation-Kmeans-dbscan-clustering)

### 2. Telco Customer Churn Prediction

Developed an end-to-end classification project using data from 7,043 telecom customers. Compared six machine learning models and achieved **0.844 ROC-AUC** with **77% recall** for customers likely to churn. Identified churn patterns and proposed customer retention strategies.

**Tech Stack:** Python · Pandas · Scikit-learn · XGBoost · SMOTE

[![View Project](https://img.shields.io/badge/View_Project-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/sakibzzz641/Telco-Customer-Churn-Prediction)

### 3. Medical Insurance Cost Prediction

Built an end-to-end regression pipeline using 1,337 insurance records. Applied feature engineering, five-fold cross-validation, and hyperparameter tuning to compare eight models, achieving an **R² score of 0.85**. Used SHAP to interpret key insurance cost drivers.

**Tech Stack:** Python · Pandas · Scikit-learn · XGBoost · SHAP

[![View Project](https://img.shields.io/badge/View_Project-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/sakibzzz641/Insurance-charges-regression)
